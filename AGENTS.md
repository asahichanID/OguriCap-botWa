# ATURAN UTAMA DAN MUTLAK PROYEK

## 1. LARANGAN KERAS PENGHAPUSAN FILE
- **DILARANG KERAS MENGHAPUS FILE ATAU DIREKTORI APAPUN** di seluruh proyek (termasuk di `node_modules`, `OguriCap/`, `src/`, atau root) tanpa instruksi atau izin eksplisit langsung dari pengguna.
- Tidak boleh memanggil perintah `rm`, `delete_file`, `delete_dir`, atau menghapus file apa pun dengan alasan apa pun kecuali pengguna secara tertulis memerintahkan untuk menghapus file spesifik tersebut.

## 2. PENANGANAN PERBAIKAN & MODIFIKASI
- Lakukan perbaikan melalui modifikasi berkas (`edit_file` / `multi_edit_file`), bukan dengan menghapus lalu membuat ulang atau menghapus dependensi.
- Pastikan stabilitas bot WhatsApp OguriCap dan server web selalu terjaga tanpa mengganggu file yang sudah ada.
